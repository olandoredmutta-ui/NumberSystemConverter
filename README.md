Number System Converter
A Flutter and Dart application that converts numbers between four common number systems: Binary, Octal, Decimal, and Hexadecimal.
Features
Convert numbers between four number systems.
Select the input number system.
View the equivalent values in the other number systems.
Validate input to help prevent invalid conversions.
Simple, user-friendly interface.

How to Run the Project
Install the Flutter SDK.
Install Visual Studio Code and the Flutter extension.
Clone this repository.
Open the project folder in Visual Studio Code.
Run flutter pub get in the terminal.
Run flutter run -d chrome to launch the application in Chrome.
